# PropChain - Real Estate Property Registry

A blockchain-based property registry system for transparent real estate transactions and ownership verification.

## Features
- Property registration and ownership tracking
- Real estate agent verification
- Property transaction validation
- Ownership history transparency

## Smart Contract Functions
- Register certified real estate agents
- Record property listings
- Validate property transactions
- Track ownership changes

## Usage
Provides immutable property records and ownership verification on Stacks blockchain.
